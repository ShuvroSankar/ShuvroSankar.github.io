# Shuvro Sankar Sen: Portfolio

Personal portfolio site for my data engineering and machine learning work.

**Live site:** https://shuvrosankar.github.io

## What's on it

- Data engineering projects (BigQuery, Azure, Looker Studio)
- Machine learning and AI research
- Embedded and IoT work
- Experience, education and skills

## Built with

Plain HTML and CSS, with no frameworks and no build step. Hosted on GitHub Pages.

## Run it locally

Open the folder in VS Code and use the Live Server extension, or run:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Structure

```
index.html   page content
style.css    styles (light and dark mode follow the system setting)
assets/      project screenshots and diagrams
```
